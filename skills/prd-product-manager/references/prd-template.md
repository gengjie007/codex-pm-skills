# 三 状态机说明（如适用）

## 状态定义

| 状态   | 说明         |
| ------ | ------------ |
| 创建中 | 正在初始化   |
| 生效中 | 正在下发策略 |
| 已生效 | 规则生效     |
| 删除中 | 正在清理资源 |

## 状态流转规则

- 创建中 → 生效中 → 已生效
- 已生效 → 删除中 → 删除完成

------

# 四 交互与权限说明（如适用）

## 操作与状态关系

| 当前状态 | 是否允许编辑 | 是否允许删除     | 是否允许关联子网 |
| -------- | ------------ | ---------------- | ---------------- |
| 创建中   | 否           | 否               | 否               |
| 已生效   | 是           | 是（需满足约束） | 是               |

------

# 五 数据限制说明

- 单个VPC最多可创建 20 个网络ACL实例
- 单个子网仅可关联 1 个网络ACL实例
- 协议与端口格式必须符合规范
- 优先级不可重复

------

# 六 非功能性要求

- 接口响应时间 ≤ 3s
- 批量操作需支持 50 条以内规则
- 操作必须有二次确认提示

------

# 七 风险与边界说明

- 与VPC删除逻辑存在强依赖
- 子网状态机需与ACL状态联动
- 默认规则不可被修改
